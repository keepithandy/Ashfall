# Player asset study 02

This standalone Godot project is version two of the hands and flashlight review asset. The parent game's importer skips the previews folder. Open this project's project.godot separately to review the asset; it does not replace the playable character.

Changes: knuckle creases and wear variation on the gloves; darker reinforcement panels; material roughness maps for canvas and leather; more concentrated sleeve folds; bound cuffs, closure tabs, and press studs; shared skeletal motion for the gloves, sleeves, and flashlight.

Open `Open Preview.cmd`. Tab changes camera mode, the mouse wheel rotates the studio view, F toggles the light, L changes lighting, A toggles the test motion, and Escape quits. The PNG files are actual Godot renders. The original Blender source and exported GLB are included.

This remains a modeling draft. The grip silhouette, tailoring and wear still need artistic refinement to reach the approved concept. It is not yet a finished or optimized player animation set.

Checks passed for both gloves being continuous meshes with normalized skin weights, Godot import of the 36-bone rig and two skinned meshes, preview controls, and the flashlight following the animated rig.
