# Field pack and usable item test kit

Run **Inspect Inventory.cmd** to start an expedition with the pack open, or
press **Tab** during normal gameplay. **Tab**, **Escape** or the **Close** button
closes the pack. Player movement, held-item transitions and the creature pause
while the pack is open.

## Starter equipment

Every new expedition includes all eight items so grip testing needs no looting.

| Item | Starting count | Use |
| --- | ---: | --- |
| Flashlight | 1 | Toggle beam; F also works while carried |
| Canned provisions | 2 | Restore 45 stamina |
| Cotton bandage | 2 | Restore 35 condition |
| Spare batteries | 2 | Restore 60 flashlight charge |
| Water flask | 2 | Restore 30 stamina |
| Antiseptic | 2 | Restore 20 condition |
| Anomaly meter | 1 | Carry and toggle nearest anomaly readout within 40 m |
| Field receiver | 1 | Objective bearing and distance; changes to the gate after sample pickup |

Restoration caps at 100. Supplies are not consumed at full stats. An exhausted
carried stack returns the hand to the flashlight if available. Stacks cannot go
negative. The existing H/G/R supply shortcuts still work. **Q** uses the selected
carried item during gameplay. The receiver is a local game mechanic.

## Select, carry and use

The pack shows a simple grid of item icons and quantities. Select a slot, then
choose **Carry**, **Use** or **Stow**. Empty stacks appear as empty slots. Equip
changes queue while the game is paused and perform the existing smooth exchange
after closing the pack. The previous hand-inspection tools remain available as
separate development scenes; they no longer run inside the inventory.

Contact dots show the terminal bone guide and its authored target, slightly
outside the prop surface. They check import fidelity; they do not prove the skin
cannot intersect any part of a model. New poses are fitted starting points for
artistic review. This adds held test items and inventory actions, not drinking,
bandaging or pickup animations, physical dropping, or persistent saves.

## Editable assets and export

- `item_catalog.gd`: item definitions, display order, effects and starter counts.
- `scenes/items/held_*.tscn`: six new standalone static props; no text labels on
  their meshes. The existing flashlight and food tin retain their approved assets.
- `assets/grips/*.tres`: per-item attachment, targets, fallback joints and pose name.
- `assets/characters/inventory_hands/source/inventory_hand_poses.blend`: separate
  editable Blender source for the six added pose assets.
- `assets/characters/inventory_hands/hand_poses.res`: six extracted finger clips,
  loaded by the existing full-body character. No extra player skeleton is spawned.

The original `hand_authoring.blend`, approved flashlight/tin clips and editable
village scene have not been regenerated by this work. The new props use original
geometry and existing project materials; no newly downloaded assets are included.

Use **Export Blender Hand to Game.cmd** in the Codex output folder after saving
Blender edits. It exports both saved sources, imports the GLBs and extracts the
inventory pose library. Restart the running game to load saved changes.

`tools/build_inventory_hand_library.py` and `tools/fit_inventory_grips.py` are
initial authoring tools. Do not rerun them over manually refined poses. The source
builder refuses to overwrite an existing file without `--rebuild`.
`tools/bake_usable_items.gd` regenerates the six prop scenes and
`tools/bake_item_icons.gd` renders their inventory icons; these overwrite their
generated outputs, so preserve manual edits before running them.

## Verification

`tests/test_inventory_items.gd` exercises all eight actual imported grips, inward
curl, guide drift below 5 mm, pose playback without quaternion fallbacks, independent
diagnostic/player hands, steep aim/crouch/wall/walk examples, inventory slots,
pause/input, gameplay swaps, stowing, restoration limits, empty stacks, automatic
fallback and detector/receiver actions. Existing authored-hand, transition,
held-item, full-body, expedition and rendered smoke checks remain relevant.
`tests/test_inventory_grid.gd` checks the grid and item actions in the main world.

`--inventory-review` creates actual engine renders under `reviews/inventory/`.
